# 💈 Under 23

Landing page desarrollada para **Under 23**, una barbería de la ciudad de Córdoba, Argentina.

Este proyecto corresponde a una **V1 / demo**, desarrollada como base para una futura versión con más información, funcionalidades y contenido real.

🔗 **Demo:** https://underbarbershop.vercel.app/

---

## 📌 Sobre el proyecto

El objetivo fue crear una web moderna, simple y responsive que permita presentar la barbería y su propuesta de una forma clara y visual.

El proyecto fue desarrollado desde cero, comenzando por la estructura y diseño de la página, pasando por el desarrollo de los componentes, adaptación responsive, ajustes visuales y finalmente el despliegue.

Esta primera versión funciona como una base sobre la cual se pueden seguir incorporando nuevas funcionalidades y contenido.

## 💻 Instalación y uso

Para ejecutar el proyecto localmente:

### 1. Clonar el repositorio

```bash
git clone https://github.com/javiGomezCba/Under-23.git
```

### 2. Entrar al proyecto

```bash
cd Under-23
```

### 3. Instalar dependencias

```bash
npm install
```

### 4. Ejecutar el servidor de desarrollo

```bash
npm run dev
```

Luego abrir la URL que muestra Vite en la terminal, normalmente:

```text
http://localhost:5173
```
